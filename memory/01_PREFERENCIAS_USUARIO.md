# 01 — PREFERÊNCIAS DO USUÁRIO

Este arquivo registra preferências operacionais do usuário para trabalho com IA.

---

## Estilo de resposta

O usuário prefere:

- resposta direta
- passo a passo prático
- comandos prontos para terminal Linux
- indicação clara de onde criar cada arquivo
- conteúdo completo dos arquivos
- pouca teoria
- pouca explicação desnecessária
- foco em execução

---

## O usuário não quer

- hipóteses longas
- excesso de opções
- explicações repetitivas
- estrutura grande sem necessidade
- prompts gigantes
- arquivos demais
- resposta dizendo apenas "eu faria"
- sugestões sem conteúdo exato

---

## Forma ideal de entrega

Quando pedir criação de estrutura, entregar:

1. nome da pasta
2. caminho exato do arquivo
3. conteúdo completo
4. comando para criar via terminal
5. comando para conferir

---

## Decisões operacionais

A estrutura de IA deve ser:

- simples
- copiável para outros projetos
- reutilizável
- curta
- orientada a economia de contexto
- compatível com Claude Code
- adequada para projetos Go, Next.js e Supabase

---

## Regra final

Sempre preferir execução objetiva em vez de explicação longa.
