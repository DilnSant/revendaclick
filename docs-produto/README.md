# docs-produto — Documentação de produto validada

Conteúdo trazido em 2026-07-31 de um repositório de planejamento separado (`RevendaClick`, descontinuado), onde a visão, requisitos, modelagem de dados, regras de negócio, glossário e roadmap do RevendaClick foram validados ponto a ponto com o responsável do produto. Todos os documentos aqui foram confirmados explicitamente, não são rascunho.

Distinto de `docs-operacao/`, que descreve a realidade operacional atual do sistema em produção (como as coisas *são*); esta pasta descreve decisões de produto e domínio (o que o sistema *deve fazer*) — as duas devem ser lidas em conjunto ao planejar uma mudança: `docs-produto/` para a regra de negócio pretendida, `docs-operacao/` para como o código real implementa (ou ainda não implementa) essa regra.
